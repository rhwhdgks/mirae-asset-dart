# DART 공시 Agent

2026 미래에셋증권 AI Festival 공시 Agent 과제에서 개발한 코드를 개인 포트폴리오용으로 분리한 저장소입니다. 주최 측의 공식 서비스가 아니며, 대회 제출 저장소 및 평가 서버와 연결되지 않습니다.

## 무엇을 하는가

공시 질문을 해석해 조회 계획을 만들고(`agent/`), 공시 원문을 구조화한 자료에서 근거를 찾아(`src/`, `app/`), 숫자·기간·단위를 확인한 뒤 출처가 있는 답변으로 조합합니다(`app/`, `server/`). 답변할 근거가 없거나 질문이 모호하면 한계를 알리거나 되묻도록 설계했습니다.

## 공개 범위

이 저장소에는 구현 코드와 데이터 없이 실행할 수 있는 일부 테스트만 있습니다. 주최 측 제공 공시 원문과 그 파생 정본·검색 인덱스, 평가 질문·정답·근거, 운영 서버 정보, 실행 로그, API 키는 포함하지 않았습니다. 따라서 이 저장소만 내려받아서는 전체 답변 API를 실행하거나 대회 결과를 재현할 수 없습니다.

실행에 필요한 공시 데이터와 HyperCLOVA X 자격 증명은 각각의 이용 조건에 따라 별도로 준비해야 합니다. 비밀값은 `.env` 또는 환경 변수로만 주입하고 Git에 올리지 마세요. 설정 항목은 `.env.example`을 참고할 수 있습니다.

## 코드 구성과 가벼운 검증

| 경로 | 역할 |
| --- | --- |
| `agent/` | 질문 해석, 계획 및 안전 경계 |
| `src/` | 공시 전처리·정본 처리 코드 |
| `app/` | 근거 조회와 답변 조합 |
| `server/` | HTTP API |
| `scripts/` | 개발·평가 보조 스크립트(일부는 제외된 자료 필요) |
| `tests/` | 공개 가능한 오프라인 단위 테스트 일부 |

Python 3.14를 대상으로 작성했습니다. 의존성을 설치한 환경에서는 아래의 공개 테스트를 실행할 수 있습니다.

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
PYTHONPATH=. python tests/test_chunker.py
```

전체 서비스는 별도 공시 자료와 인덱스가 필요하므로 위 테스트 통과가 운영 준비 상태를 뜻하지는 않습니다.
